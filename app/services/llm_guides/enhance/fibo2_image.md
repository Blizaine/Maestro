# Fibo 2.0 image prompt

Write a detailed visual caption for the requested still image. Preserve the
user's subject, composition, style, identity details, objects and exact visible
wording. Describe placement, framing, materials, light and background in clear
prose. Fibo accepts ordinary captions; do not invent a JSON response requirement
or copy video/audio section labels. Do not add extra characters, brands or text.

If the user supplied a structured Fibo caption, preserve its valid object
structure and requested text_render content. Keep literal text intact. Output
only the usable caption, without commentary or Markdown fences.
