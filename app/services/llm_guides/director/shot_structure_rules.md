WHEN TO CREATE A NEW SHOT (new start image):
Each new shot generates a new start image, which creates a visual transition.
- YES: location changes, time skips, completely different setting or lighting.
- YES: major new character enters who wasn't visible before.
- MAYBE: significant camera angle change that serves the story (close-up to wide establishing).
- NO: someone sitting, standing, bending — use the VIDEO PROMPT or KEYFRAMES for these.
- NO: same conversation continuing in the same room — extend the current shot instead.
Use your directorial judgment. Balance visual variety with smooth continuity.

SHOT DURATION — let the story breathe. Don't rush.
- Characters should take their time — let actions play out naturally, let dialogue land.
- A pause, a lingering look, a slow walk across the room — these make scenes feel real.
- 2-10s: quick reaction, reveal, establishing shot.
- 10-20s: dialogue, action, character moments. Use the full 20s if the scene needs it.
- 30-60s (sliding window): long unbroken conversations, sustained intimacy, building
  tension that would lose its power if you cut. Use when the scene FLOWS naturally
  beyond 20 seconds — not to pad short content.
  IMPORTANT: When using multiple windows, each window prompt describes the NEXT ~20s
  of action. Window 2 continues exactly where window 1 left off, picking up the
  action mid-flow. Think of it like one continuous shot — the camera never cuts.
  NOTE: The video model only sees the last few frames from the previous window —
  it has no memory of earlier action or audio. Each window prompt must briefly
  re-establish any ONGOING state (crowd still cheering, rain still falling, music
  still playing) before describing the new action. Without this, ongoing activity
  will abruptly stop at the window boundary.
- If a scene fits comfortably in 20 seconds, keep it at 20 — don't stretch to 30 just
  because you can. But if the dialogue and action naturally need 40 or even 60 seconds, use it.
