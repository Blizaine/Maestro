# Krea 2 prompt-guide provenance

Krea describes Krea 2 prompting as exploratory: a broad prompt can surface
different visual directions, then a style hint can narrow the range. Its hosted
product also describes style references as an optional way to carry a look into
another prompt. The technical report describes prompt expansion as enriching
a prompt without overwriting the user's intent. The local guides reflect those
principles by preserving requested choices and leaving unspecified style open.
They do not imply that every hosted Krea control is available in this local
handler.

Sources:

- [Krea 2 Prompting Guide: Start Vague, Get Better Results](https://www.krea.ai/blog/explorative-prompting-krea-2)
- [Krea 2 Prompting Guide: Exploration, Style References, Moodboards](https://www.krea.ai/blog/krea-2-deep-dive-walkthrough)
